Features

Built for careful listening.

Built natively on Apple’s audio frameworks. Shape a track, see what changed, and compare without loudness bias.

🎚️

Graphic & parametric EQ

10- and 31-band graphic EQ on ISO frequencies, or a 5-band parametric EQ with an interactive curve. Drag nodes, scroll for Q, double-click to type exact values.

🎧

Headphone-ready correction

Keep calibration, target curve and session tuning separate. Browse AutoEQ-style profiles or import AutoEQ and REW files.

⚖️

Level-matched A/B

Automatic RMS offset detection with click-free crossfades removes loudness bias when comparing. Undo, redo and A/B/C snapshot slots included.

📈

True-peak metering

ITU-R BS.1770 true-peak (dBTP) with 4× oversampling, RMS, headroom and peak hold. Auto Headroom lowers the preamp before boosts can clip.

🌈

Live spectrum

64-band FFT spectrum powered by vDSP, in seven styles: Neon, Aurora, Ember, Prism, Orbit, Matrix and Globe. Optionally live in your menu bar.

🧭

Menu bar, Dock or both

Control System Audio, bypass, output and every built-in preset from a compact menu bar panel without opening the main window.

🔌

Dynamics & Audio Units

Use a compressor, stereo balance, an always-on peak limiter, and Audio Unit effects in the local playback chain.

Experimental

System-wide EQ, clearly marked experimental.

System-Wide EQ uses a Core Audio process tap instead of an installed audio driver. It is useful on supported setups, but local playback remains OpenEQ’s stable core.

How it works

  • System-Wide EQ — one click taps system audio, runs it through EQ and a limiter, and plays it on your output device.
  • Routing Lab — a node graph for testing one system, app or input signal path at a time.
  • External Loopback — process a virtual input such as BlackHole as an advanced fallback.

Built-in safety

  • Feedback guard mutes sustained hot signals to stop howling.
  • Safe mode restores your original default output in one step.
  • Sleep and wake recovery keeps the chain running after your Mac sleeps.
  • Per-device profiles remember a preset for each output device.

Requires macOS 14.2 or later and Screen & System Audio Recording permission.

Compatibility note: OpenEQ does not install an audio driver, but System-Wide EQ is not compatible with the eqMac HAL driver. Remove eqMac before using System-Wide EQ. Other third-party HAL audio drivers can also conflict with this experimental feature.
